# Ring — Priceless

A responsive recreation of the supplied example.mp4. Open dist/index.html directly or run `python -m http.server 4173 --directory dist` from this directory.

Drag the ruler, tap its position, or focus it and use arrow keys. Home selects the diamond; End selects Priceless. Nine stages update the artwork, description and price. The last stage fades to a dark background and a CSS light ring. Reduced-motion preferences are respected.

Product images are cropped from the user's reference video, not original product photography. Some product descriptions are approximations where the recording is unclear. The prices reproduce the reference and are not current retail quotations.
